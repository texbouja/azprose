# Aide-mémoire des raccourcis

Les raccourcis sont donnés pour macOS (`⌘` = Commande). Sur Windows et Linux, remplacez `⌘` par `Ctrl`.

> [!note] Tout est personnalisable
> Chaque raccourci peut être modifié dans les réglages. Et si vous oubliez un raccourci : la palette de commandes (`⌘⇧P` / `Ctrl+⇧P`) permet de tout faire.

## Enregistrer et ouvrir

| Action | Raccourci |
|--------|-----------|
| Enregistrer la note courante | `⌘S` |
| Créer un nouveau fichier | `⌘N` |
| Ouvrir un fichier | `⌘O` |
| Ouvrir un projet (dossier) | `⌘⇧O` |
| Exporter la note en PDF | `⌘P` |
| Annuler la dernière opération de fichier (déplacement, renommage…) | `⌘⌥Z` |

## Travailler sur une note

| Action | Raccourci |
|--------|-----------|
| Mode source (Markdown brut) | `⌘1` |
| Mode écriture | `⌘2` |
| Mode aperçu | `⌘3` |
| Ouvrir/fermer le panneau d'aperçu | `⌘\` |

## Naviguer dans l'application

| Action | Raccourci |
|--------|-----------|
| Palette de commandes | `⌘⇧P` |
| Explorateur (barre latérale gauche) | `⌘B` |
| Console | `⌘⇧C` |
| Réglages | `⌘,` |
| Plein écran | `⌃⌘F` (ou `F11`) |
| Compiler le document LaTeX (.tex) | `⌘⌥B` |

## Astuces de navigation

- **Double-clic dans l'aperçu** : ramène l'éditeur à la ligne correspondante.
- **`⌘S`** : après un enregistrement, l'aperçu se place automatiquement sur la ligne du curseur.
- **Clic sur un lien** : ouvre la note dans le panneau d'aperçu (`⌘\`).
- **`Alt + glisser` sur un PDF** : sélectionne une zone rectangulaire et copie son lien (voir [[wikilinks]]).
